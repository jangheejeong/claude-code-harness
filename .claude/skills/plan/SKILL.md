# Plan

1. Identify the target repository and read its requirements and relevant existing plan.
2. Use `explorer` only when bounded code discovery will materially improve the plan.
3. Ask `planner` for the smallest testable phases, risks, non-goals, and observable done conditions.
4. Save the approved result to the target repository's `Plans.md`. Stop before implementation until the user approves it.
